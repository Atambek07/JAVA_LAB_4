### Код

**1. В `BookController.java` — метод списка:**

```java
@GetMapping
public PageResponse<BookResponse> findAll(
        @RequestParam(value = "q", required = false) String q,
        @PageableDefault(size = 10) Pageable pageable) {

    validatePageable(pageable);

    Page<Book> page = library.findBooks(q, pageable);
    return PageResponse.from(page.map(book ->
            BookResponse.from(book, library.availableCopies(book.getIsbn()))));
}

private static final Set<String> ALLOWED_SORT_FIELDS = Set.of("title", "year");
private static final int MAX_PAGE_SIZE = 100;

private void validatePageable(Pageable pageable) {
    if (pageable.getPageSize() > MAX_PAGE_SIZE) {
        throw new IllegalArgumentException(
                "Размер страницы не может быть больше " + MAX_PAGE_SIZE
                        + ", получено: " + pageable.getPageSize());
    }
    List<String> invalid = pageable.getSort().stream()
            .map(Order::getProperty)
            .filter(p -> !ALLOWED_SORT_FIELDS.contains(p))
            .toList();
    if (!invalid.isEmpty()) {
        throw new InvalidSortException(invalid, ALLOWED_SORT_FIELDS);
    }
}
```

### Объяснение

- `ALLOWED_SORT_FIELDS` — белый список, чтобы клиент не мог сортировать по произвольным внутренним полям.

```java
package kg.course.library.repository;

import org.springframework.data.jpa.domain.Specification;
import kg.course.library.entity.Book;
import kg.course.library.entity.Loan;

import jakarta.persistence.criteria.*;

public class BookSpecifications {

    public static Specification<Book> hasTitle(String fragment) {
        return (root, query, cb) -> {
            if (fragment == null || fragment.isBlank()) return null;
            return cb.like(cb.lower(root.get("title")),
                    "%" + fragment.trim().toLowerCase() + "%");
        };
    }

    public static Specification<Book> hasAuthor(String authorName) {
        return (root, query, cb) -> {
            if (authorName == null || authorName.isBlank()) return null;
            var authors = root.join("authors");
            return cb.equal(cb.lower(authors.get("name")),
                    authorName.trim().toLowerCase());
        };
    }

    public static Specification<Book> yearBetween(Integer yearFrom, Integer yearTo) {
        return (root, query, cb) -> {
            if (yearFrom == null && yearTo == null) return null;
            Path<Integer> year = root.get("year");
            if (yearFrom != null && yearTo != null) {
                return cb.between(year, yearFrom, yearTo);
            }
            if (yearFrom != null) return cb.greaterThanOrEqualTo(year, yearFrom);
            return cb.lessThanOrEqualTo(year, yearTo);
        };
    }

    public static Specification<Book> hasAvailableCopies() {
        return (root, query, cb) -> {
            Subquery<Long> sub = query.subquery(Long.class);
            Root<Loan> loan = sub.from(Loan.class);
            sub.select(cb.count(loan)).where(
                    cb.equal(loan.get("book"), root),
                    cb.isNull(loan.get("returnedOn")));
            return cb.greaterThan(root.get("copies"), sub);
        };
    }

    public static Specification<Book> search(String title, String author,
                                             Integer yearFrom, Integer yearTo,
                                             Boolean available) {
        Specification<Book> spec = Specification.where(hasTitle(title));
        spec = spec.and(hasAuthor(author));
        spec = spec.and(yearBetween(yearFrom, yearTo));
        if (Boolean.TRUE.equals(available)) {
            spec = spec.and(hasAvailableCopies());
        }
        return spec;
    }
}
```

### Объяснение
- `Specification<T>` — функциональный интерфейс Spring Data JPA, который строит предикат `Predicate` через Criteria API.

### Код

**1. `LoanSpecifications.java` — новый файл:**

```java
package kg.course.library.repository;

import org.springframework.data.jpa.domain.Specification;
import kg.course.library.entity.Loan;

import jakarta.persistence.criteria.*;
import java.time.LocalDate;

public class LoanSpecifications {

    public static Specification<Loan> hasCardNumber(String cardNumber) {
        return (root, query, cb) -> {
            if (cardNumber == null || cardNumber.isBlank()) return null;
            return cb.equal(root.get("reader").get("cardNumber"), cardNumber.trim());
        };
    }

    public static Specification<Loan> hasStatus(String status, LocalDate today) {
        return (root, query, cb) -> {
            if (status == null || status.isBlank()) return null;
            Predicate notReturned = cb.isNull(root.get("returnedOn"));
            return switch (status.trim().toUpperCase()) {
                case "ACTIVE"   -> notReturned;
                case "RETURNED" -> cb.isNotNull(root.get("returnedOn"));
                case "OVERDUE"  -> cb.and(notReturned,
                        cb.lessThan(root.get("dueOn"), today));
                default         -> null;
            };
        };
    }

    public static Specification<Loan> issuedFrom(LocalDate from) {
        return (root, query, cb) -> from == null ? null
                : cb.greaterThanOrEqualTo(root.get("issuedOn"), from);
    }

    public static Specification<Loan> issuedTo(LocalDate to) {
        return (root, query, cb) -> to == null ? null
                : cb.lessThanOrEqualTo(root.get("issuedOn"), to);
    }

    public static Specification<Loan> search(String cardNumber, String status,
                                             LocalDate from, LocalDate to,
                                             LocalDate today) {
        return Specification.where(hasCardNumber(cardNumber))
                .and(hasStatus(status, today))
                .and(issuedFrom(from))
                .and(issuedTo(to));
    }
}
```

**2. `LoanController.java` — метод списка:**

```java
@GetMapping
public PageResponse<LoanResponse> findAll(
        @RequestParam(required = false) String cardNumber,
        @RequestParam(required = false) String status,
        @RequestParam(required = false) @DateTimeFormat(iso = ISO.DATE) LocalDate from,
        @RequestParam(required = false) @DateTimeFormat(iso = ISO.DATE) LocalDate to,
        @RequestParam(defaultValue = "false") boolean overdue,
        @PageableDefault(size = 10, sort = "issuedOn", direction = Sort.Direction.DESC)
        Pageable pageable) {

    validatePageable(pageable);
    validateStatus(status);

    LocalDate today = LocalDate.now(clock);
    String effectiveStatus = (status == null || status.isBlank()) && overdue
            ? "OVERDUE" : status;

    Page<Loan> page = library.searchLoans(
            LoanSpecifications.search(cardNumber, effectiveStatus, from, to, today),
            pageable);

    return PageResponse.from(page.map(loan ->
            LoanResponse.from(loan, today)));
}
```

### Объяснение

## Задача 4. Оптимистическая блокировка @Version

### Что нужно сделать

```java
@Transactional
public Book updateBook(Isbn isbn, String title, int year, int copies, Integer version) {
    Book book = getBook(isbn);

    // 1. Проверка версии (оптимистическая блокировка)
    if (!Objects.equals(book.getVersion(), version)) {
        throw new ObjectOptimisticLockingFailureException(Book.class, isbn.value());
    }

    // 2. Нельзя уменьшить экземпляры ниже активных выдач
    long activeLoans = loanRepository.countByBookIsbnAndReturnedOnIsNull(isbn);
    if (copies < activeLoans) {
        throw new BookUnavailableException(
                "Нельзя уменьшить количество экземпляров до " + copies
                        + ": на руках " + activeLoans);
    }

    book.setTitle(title);
    book.setYear(year);
    book.setCopies(copies);
    return bookRepository.save(book);
}
```

**5. `ApiExceptionHandler.java` — обработчик 409:**

```java
@ExceptionHandler(ObjectOptimisticLockingFailureException.class)
public ResponseEntity<Object> handleOptimisticLock(
        ObjectOptimisticLockingFailureException ex, WebRequest request) {
    return toResponse(ex, HttpStatus.CONFLICT,
            "Данные были изменены другим пользователем: версия устарела. "
                    + "Получите актуальные данные и повторите попытку.", request);
}
```

### Объяснение
- `@Version` — Hibernate автоматически увеличивает версию при каждом `UPDATE` и добавляет `WHERE version = ?` в условие обновления.
- Если между чтением и записью версия изменилась параллельной транзакцией, `UPDATE` не находит строку → `ObjectOptimisticLockingFailureException` → 409.
- `Persistable<Isbn>` нужен, потому что у книги назначенный первичный ключ (`Isbn`). Без `isNew()` Spring Data считает объект с непустым ID существующим и вызывает `merge` вместо `persist`.
- Двухуровневая защита: явная проверка версии в сервисе + Hibernate `@Version` на уровне БД.

```java
package kg.course.library.web;

import kg.course.library.entity.Genre;
import kg.course.library.repository.GenreRepository;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.servlet.support.ServletUriComponentsBuilder;

import jakarta.validation.Valid;
import java.net.URI;
import java.util.List;

@RestController
@RequestMapping("/api/genres")
public class GenreController {

    private final GenreRepository repository;

    public GenreController(GenreRepository repository) {
        this.repository = repository;
    }

    @GetMapping
    public List<GenreResponse> findAll() {
        return repository.findAll().stream()
                .map(GenreResponse::from)
                .toList();
    }

    @GetMapping("/{id}")
    public GenreResponse findById(@PathVariable Long id) {
        Genre genre = repository.findById(id)
                .orElseThrow(() -> new NotFoundException("Жанр с id " + id + " не найден"));
        return GenreResponse.from(genre);
    }

    @PostMapping
    public ResponseEntity<GenreResponse> create(@Valid @RequestBody CreateGenreRequest request) {
        if (repository.existsByName(request.name())) {
            throw new IllegalArgumentException("Жанр с таким названием уже существует");
        }
        Genre genre = repository.save(new Genre(request.name()));
        URI location = ServletUriComponentsBuilder.fromCurrentRequest()
                .path("/{id}").buildAndExpand(genre.getId()).toUri();
        return ResponseEntity.created(location).body(GenreResponse.from(genre));
    }

    @PutMapping("/{id}")
    public GenreResponse update(@PathVariable Long id,
                                @Valid @RequestBody CreateGenreRequest request) {
        Genre genre = repository.findById(id)
                .orElseThrow(() -> new NotFoundException("Жанр с id " + id + " не найден"));
        genre.setName(request.name());
        return GenreResponse.from(repository.save(genre));
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<Void> delete(@PathVariable Long id) {
        if (!repository.existsById(id)) {
            throw new NotFoundException("Жанр с id " + id + " не найден");
        }
        repository.deleteById(id);
        return ResponseEntity.noContent().build();
    }
}
```

```java
package kg.course.library.repository;

import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Repository;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDate;
import java.util.List;

@Repository
public class ReportRepository {

    private final JdbcClient jdbcClient;

    public ReportRepository(JdbcClient jdbcClient) {
        this.jdbcClient = jdbcClient;
    }

    // ... существующие методы ...

    @Transactional(readOnly = true)
    public List<OverdueReportRow> findOverdue(LocalDate today) {
        return jdbcClient.sql("""
                SELECT l.id, b.isbn, b.title, r.card_number, r.full_name, l.due_on
                FROM loans l
                JOIN books b ON l.book_isbn = b.isbn
                JOIN readers r ON l.card_number = r.card_number
                WHERE l.returned_on IS NULL
                  AND l.due_on < ?
                ORDER BY l.due_on ASC
                """)
                .param(today)
                .query((rs, rowNum) -> new OverdueReportRow(
                        rs.getLong("id"),
                        rs.getString("isbn"),
                        rs.getString("title"),
                        rs.getString("card_number"),
                        rs.getString("full_name"),
                        rs.getDate("due_on").toLocalDate()
                ))
                .list();
    }

    public record OverdueReportRow(
            Long id, String isbn, String title,
            String cardNumber, String fullName, LocalDate dueOn) {}
}
```

```java
@GetMapping("/reports/overdue")
public List<OverdueReportResponse> overdue(
        @RequestParam @DateTimeFormat(iso = ISO.DATE) LocalDate today) {

    List<ReportRepository.OverdueReportRow> rows = reportRepository.findOverdue(today);

    return rows.stream().map(row -> {
        long daysOverdue = java.time.temporal.ChronoUnit.DAYS.between(row.dueOn(), today);
        return new OverdueReportResponse(
                row.id(), row.isbn(), row.title(),
                row.cardNumber(), row.fullName(),
                row.dueOn(), daysOverdue);
    }).toList();
}
```

### Объяснение
- `JdbcClient` — современный Spring API для работы с JDBC (альтернатива `JdbcTemplate`), удобен для простых SQL-запросов.
- `@Transactional(readOnly = true)` — помечает метод как только для чтения, оптимизация для Hibernate.
- SQL-запрос параметризован (`?`), что защищает от SQL-инъекций.
- `ChronoUnit.DAYS.between(dueOn, today)` — считает количество дней просрочки.
- DTO `OverdueReportResponse` — клиенту отдаётся только нужная информация, а не сущности БД.
